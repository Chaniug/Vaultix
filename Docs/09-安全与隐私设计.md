# 09 · 安全与隐私设计

## 1. 威胁模型

| 威胁主体 | 能力 | 防护目标 |
|---|---|---|
| T1 被动网络窃听 | 观察全部流量 | 仅能看到密文与服务端地址（TLS + 端到端加密） |
| T2 恶意服务端（含被攻陷的自托管） | 返回伪造数据、下发弱 KDF 参数 | 无法解密（无密钥）；篡改密文会被 MAC/HMAC 检出；KDF 参数下降会在 UI 告警 |
| T3 设备上的恶意 App | 读公共存储、发 Intent、悬浮窗、Accessibility | 私有目录隔离、显式 Intent + 包名校验、`HIDE_OVERLAY_WINDOWS`、防 Accessibility 抓取（敏感文本可选设为不可被辅助服务读取） |
| T4 物理接触者（短暂拿到解锁的手机） | 操作 UI | 自动锁定、重验证主密码、敏感操作二次认证 |
| T5 取证/root | 读磁盘、dump 内存 | 磁盘只有密文；内存密钥最小化驻留并清零；root 检测（仅提示，不作为唯一防线） |
| T6 备份/云同步泄露 | 拿到 `adb backup` 或云备份 | `allowBackup=false` / `dataExtractionRules` 排除；数据置于 `noBackupFilesDir` |
| T7 供应链 | 第三方库后门 | 依赖最小化、`dependencyVerification` 校验、关键加密路径只用成熟库 |

**明确不防御**：国家级别攻击、被攻破的操作系统内核、用户主动交出主密码、模拟孔洞（用相机拍摄屏幕）。

## 2. 内存安全

| 措施 | 要求 |
|---|---|
| 密钥容器 | `SecureBytes`（内部 `ByteArray`，`zero()` 用 `Arrays.fill(0)`）；**禁止** `String` 保存密码/密钥（String 不可变且驻留常量池） |
| 清零时机 | 解锁失败、锁定、页面销毁、复制完成（临时明文）、KDF 中间值 |
| 避免复制 | 加解密尽量使用 `ByteBuffer` 原地操作；`SecureBytes` 提供只读视图 |
| 禁止序列化 | `SecureBytes` **不得**实现 `Parcelable`/`Serializable`；跨进程只传密文或会话内句柄 |
| 状态保存 | `SavedStateHandle` 只存 id 与非敏感字段；进程重建后必须重新解锁 |
| 内存中的 Protected 字段 | KDBX 保护流字段保持密文，按需解密 |

## 3. 剪贴板

- 复制后启动倒计时清除（默认 60 s，可设 30/60/120/永不）。
- Android 13+ 系统会显示"已复制"气泡并在约 1 小时后清除；App 仍需自行实现。
- 提供"复制后自动清除"与"复制时提示"开关；**禁止**在 Toast/Snackbar 中回显内容。
- 提供"清除剪贴板"快捷设置磁贴。

## 4. 截图、录屏与 Recent

```kotlin
override fun onCreate(savedInstanceState: Bundle?) {
    window.setFlags(FLAG_SECURE, FLAG_SECURE)   // MUST：在 setContent 之前
    if (Build.VERSION.SDK_INT >= 33) setRecentsScreenshotEnabled(false)
    super.onCreate(savedInstanceState)
    setContent { ... }
}
```

- 适用范围：**全部** Activity（含解锁、详情、编辑、设置——设置页含库信息）。
- 已知限制：`FLAG_SECURE` 对 root、ADB 投屏、相机拍摄无效；文档中如实说明，不承诺绝对防护。
- 悬浮窗：Android 12+ 声明 `HIDE_OVERLAY_WINDOWS`；敏感页面检测到其他 App 拥有 `SYSTEM_ALERT_WINDOW` 时提示用户。

## 5. 键盘与输入法

- 主密码、密码字段设置 `imeOptions = IME_ACTION_DONE`、`keyboardType = Password`、`autoCorrect = false`。
- 提供提示：使用第三方键盘可能记录输入，建议切回系统键盘（设置项 + 首次输入引导）。
- 不实现自定义键盘（V1）；V1.5 可评估"Magikeyboard"式内置键盘以彻底规避剪贴板与第三方键盘。

## 6. 日志与调试

| 规则 | 说明 |
|---|---|
| release 无日志 | `Timber` 仅在 `BuildConfig.DEBUG` 下种树；release 使用 `NoTree` |
| 禁止打印敏感 | 自定义 Lint：`Log.*`/`Timber.*` 的参数不得来自含 `password/secret/key/token/totp` 命名的变量或 `SecureBytes` |
| 崩溃上报 | 默认关闭；开启后剥离 `VaultItem` 内容，只保留堆栈与匿名计数 |
| 网络日志 | OkHttp 日志拦截器仅 debug；禁止在生产开启 `BODY` 级别 |
| `adb bugreport` | 保证系统转储中不含明文（依赖上述内存与磁盘策略） |

## 7. 数据存储清单

| 数据 | 位置 | 保护 |
|---|---|---|
| 条目密文缓存 | Room（`noBackupFilesDir`） | 已是密文；库文件不额外加密 |
| 搜索索引 | Room FTS5 | **仅**标题/域名/用户名（可关），不含密码/笔记/密钥 |
| 账号对称密钥 | 内存 | `SecureBytes`，锁定清零 |
| 生物识别解锁凭据 | `EncryptedSharedPreferences` | Keystore AES-GCM + 生物识别门禁 |
| OAuth token | `EncryptedSharedPreferences` | Keystore AES-GCM（无门禁以便后台续期） |
| 设置 | DataStore（明文） | 不含敏感值；"服务器地址"属敏感，单列并允许隐藏 |
| KDBX 文件 | 用户指定位置（SAF） | 用户自控；应用内不长期保留副本 |
| 图标缓存 | 内部缓存目录 | 非备份目录；可一键清除 |
| 生成器历史 | 加密存储 | 复用 Keystore 密钥，默认保留 20 条 |

## 8. Root / 完整性

- 检测仅用于**提示**（"检测到设备已 root，建议…"），不作为硬性拦截（避免误报与可访问性问题）。
- 不接入 SafetyNet/Play Integrity（避免引入 Google 依赖与隐私争议）；离线版 flavor 完全无网络。

## 9. 隐私承诺（面向用户）

1. 不收集任何分析数据、不集成广告、不集成崩溃 SDK（除非用户主动开启）。
2. 主密码、密钥永不出设备（Bitwarden 只发送主密码派生的哈希）。
3. 网络请求仅三类：① Bitwarden 服务端 API ② 网站图标（默认关闭）③ 泄露密码查询（默认关闭）。
4. 所有网络行为在设置中有开关与说明。
5. 开源：全部代码可审计，构建可复现（提供 `reproducible build` 说明与签名指纹）。
