## 0. 一句话结论

三块不是三个独立项目，而是**同一个问题的三个面**：

> 项目已经有 **5 张设计令牌表**（Spacing / UiSize / VaultixCorner / VaultixShapes /  
> VaultixTypography），但「谁该用哪一档」没有被强制执行 —— 于是同一件事在不同页面  
> 各有写法，而每一处写法都能自证"我是对的"。

⇒ 顺序必须是 **先收口（B0，零视觉变化）→ 再改皮（B1/B2/B3）**。  
反过来做，每改一屏就多一套规格，三个月后又要审计一次。

## 3. 硬红线（违反即返工，不讨论）

1. **转场只允许 `translationX` / 现有 fade+slide**；禁止形状变形（cookie/clover）、  
   bump、弹性过冲。用户原话：「不要花里胡哨的动画」（#87）。
2. **不采纳强调排印**：不放大字号、不把标题加粗。顶栏标题刚从 32sp 收到 26sp。
3. **品牌色只允许出现在两处**：App 启动图标、首启页两个入口按钮。  
   **不许**把品牌蓝铺进普通 UI（8.8 §6②）。
4. **嵌套容器必须换色档**，往低走（`Lowest`）；禁止同色叠 alpha —— 卡片边界会彻底消失。
5. **卡片必须显式 `containerColor`**：`CardDefaults` 默认是 `Highest`（1.232），  
   不传就自动违规，列表里每张卡都是一块色斑。
6. **Dialog / BottomSheet 里不做 Popup 选择器**：菜单里的输入框收不到 IME、  
   列表画到屏幕外（#257）。
7. **让位做在滚动内容里**（`contentPadding` / `Spacer`），**绝不**做外层容器 padding。
8. **detekt 四条硬线**：`LongMethod ≤150` / `LargeClass ≤1200` / 参数 ≤8 /  
   类内函数 ≤40；`buildUponDefaultConfig = true`（少这个参数 = 假绿）。

## 4. 分批方案

### B0 · 收口（**零视觉变化**，建议先做）

> 目的：让后面三批「改一个数就是改全局」，而不是每屏各改一遍。

| # | 做什么                                                              | 影响面           |
| - | ---------------------------------------------------------------- | ------------- |
| 1 | 剩余 ~166 处字面量按「值不变」归位到 5 张表                                       | 全局，纯等价替换      |
| 2 | `SiteIcon` 的 `Color.White` 提成语义 token（如 `VaultixTint.IconPlate`） | 一处定义，为 B2 铺路  |
| 3 | 把散落的 `copy(alpha=)` 收进 `VaultixTint`（详情页 8 处优先）                  | 详情页 / 表单      |
| 4 | 产出「共享组件规格表」：每个组件用哪档圆角 / 间距 / 字阶                                  | 一页纸，作为 B3 的尺子 |

**验收**：`git diff` 只应出现 token 名替换（值不变）；用 8.8 P0-1 的**反演法**逐文件比对  
（把 token 展开回数值，与改前逐字符一致）。**这一批要的是零风险，不是好看。**

### B1 · 底部功能栏

- **目标**：在不推翻「叠层悬浮胶囊」的前提下，做出层次与呼吸。
- **可动**：胶囊高度 / 图标与文字的尺寸关系 / 选中 pill 形状与色档 /  
  按压反馈曲线 / 玻璃态默认值。
- **禁动**：叠层悬浮架构、`rememberBottomDockInset` 公式、选中色瞬切、  
  中央「+」不是 FAB、实色与玻璃共用 `DockRow`。
- **验收**：默认字号 + 2.0x 字号各一屏；浅色 / 深色 / 纯黑 / 玻璃开 四种组合各一张截图；  
  最后一条列表项不被压住。

### B2 · 品牌图标

- **A 启动图标**（用户已选定，**本轮先做**）：⚠️ 原写「重绘前景几何」**方向有误** ——  
  几何经 V1→V5 五轮校准、用户两次拍板，是本项目最不能动的部分。  
  已单独展开为专项施工单 → [`app-icon-plan.md`](./app-icon-plan.md)  
  （配色滞后实证 / 生成脚本丢失的接力断层 / 三个设计方向 / 不依赖编译的验收）。
- **B 品牌包**：只改 `slugs.txt` 重跑脚本，**不手改** `BrandIconCatalog.kt`。
- **C 条目图标**：补深色分支（解决「死白圆盘」）、圆 vs 圆角方的取舍、  
  首字母兜底的对比度。
- **验收**：浅 / 深 / 纯黑 × 动态取色开 / 关，各一张列表图；同一屏内不得出现  
  「白圆盘 + 彩色圆底」两种视觉重量。

### B3 · 页面精装修

- **顺序**：共享组件（`EntryCard` / `EmptyState` / `SelectionActionBar` / `DialogShell`）  
  → 四个 Tab → 二级页。**先做减法（统一规格），再做加法（图标 / 间距）。**
- **第一步不是改代码，是「观感审计」**：按 8.4 既有判据逐页扫  
  （一屏两套规格 / 同色叠 alpha / 一个元素说两件事 / 动作区不对齐），  
  产出一张「页面 → 问题 → 证据」表，再排优先级。

## 5. 每批的统一门禁

| 关      | 命令 / 方式                       | 备注                                                     |
| ------ | ----------------------------- | ------------------------------------------------------ |
| 编译     | CI（本机 **不可编译**：AGP 9.5.0 缺缓存） | push `main` 触发                                         |
| detekt | `./gradlew detekt`            | 必须带 `buildUponDefaultConfig`；本地 CLI 不加 = 0 findings 假绿 |
| 单测     | `testFullDebugUnitTest`       | 触到 `SiteIcon` / 颜色时尤其要跑                                |
| 真机     | 浅色 + 深色各一屏截图                  | 「用户看得到、我复现不了」⇒ 先取证再动代码                                 |

⚠️ **三关分开单跑**，串成一条会 `Gradle build daemon disappeared`（环境崩，不是代码错）。  
⚠️ CI 里 detekt 跑在编译**之前**：detekt 红 ⇒ 后面一个都不跑，别被「没编译」误导。
