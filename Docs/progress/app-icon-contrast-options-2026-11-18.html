注意一个物理限制

同一个蓝底 `#3B5BC4` 下，「白 / 折痕 / 底」三档不可能同时拉开：

折痕色白 / 折痕折痕 / 蓝底结果
#B9C6F0 现行1.69 ❌3.56 ✅折痕糊，V 不显眼
#9CAEE62.19 ⚠2.76 ⚠两头都不够
#7690D43.13 ✅1.93 ❌折痕看得见，但右半融进底
出路只有一条：把底压深。底压深到 `#1B2B63`（或 `#2F3B4A`）后，折痕 `#7690D4` 能同时拿到 白/折 3.13、折/底 4.27、白/底 13.36 ——三档全拉开。 而且深海军蓝和 Bitwarden 的亮蓝 #175DDC、1Password 的 #0572EC 明显不同， 一个改动同时解决你说的两件事。

请拍板

  1. 选一个配色方案编号：① 现行 ④ 深海军蓝+中折痕 ⑤ 更深底+高对比折痕 等。
  2. 如果选深底，App 内主题色仍按之前拍板保留现行低饱和蓝——图标与界面会有一档明度差，这在品牌上叫「图标是界面的深色印章」，不算割裂；你要是介意我再给同底方案。

这批改的是 res/values/colors.xml 里三个 ic_launcher_* 值 + 图标几何脚本的色值常量； 几何 path 与门禁不动，CI 图标一致性检查会验证「只有颜色变了」。
