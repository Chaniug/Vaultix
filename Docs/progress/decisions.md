| 2026-09-10 | **🔴 CP 库锁定时必须走 `authenticationActions`（照抄 Bitwarden）** | 此前锁定时把「解锁 Vaultix」伪装成一条 `CredentialEntry`（按 option 类型生成 `PasswordCredentialEntry`/`PublicKeyCredentialEntry`）塞进 `credentialEntries` → 系统按**凭据语义**处理该条目，点击后既不回灌凭据、也不是认证动作 → 真机表现为「点解锁毫无反应、进不去」。Bitwarden `CredentialProviderProcessorImpl.processGetCredentialRequest` 的正确做法：`callback.onResult(BeginGetCredentialResponse(authenticationActions = listOf(authenticationAction)))` + `return`。**两个通道语义不同、不可混用**：`credentialEntries` = 可填凭据（要求 `setGetCredentialResponse` 回灌）；`authenticationActions` = 认证动作（系统渲染为独立「解锁」操作，解锁后**重新**发起 `onBeginGetCredentialRequest`，两段式）。已改 `unlockAction()`（`AuthenticationAction.Builder(title, pendingIntent)`），删除 `unlockEntry()` |
