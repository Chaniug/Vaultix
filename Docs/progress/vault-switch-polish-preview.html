B库列表 · 四种外观

① 是你截图里的现状；② 是推荐的「库身份卡」；③ 加统计信息；④ 是最大胆的全 M3E vibrant。

为什么推荐 A（容器展开）+ ②（库身份卡）

动效：container transform 把「切库」的因果画出来了——点的是那张卡，展开的也是那张卡， 而不是一个与点击无关的整屏淡入。200–260ms，比 M3E 的 400ms 中档更短，不拖慢切库。 C（纵深换层）是最稳的备选：只改透明度与缩放，不动布局尺寸。

库列表：现在的问题是大片空白 + 两张同色灰卡 + 一个孤零零的 FAB，没有视觉锚点。 ② 给每个库一个 48dp 形状徽章，颜色全部取自 colorScheme 的 tonal 角色 （不硬编码品牌色，动态取色安全），形状按库类型区分：云端 squircle / 本地圆角方 / 云盘圆形。 空白区改成一张「当前活跃库」摘要卡，填空白的同时给的是真信息，比装饰插画耐看。

三条不能忘的历史证据： ① MainShellScreen 的 Tab AnimatedContent 把 SizeTransform 关成瞬时，因为返回时重进组合会重放转场、把详情页裁小 1–2 帧； ② skipFirstTransition 挡的是「重新进入组合」的重放，切库是另一个事件，状态要独立； ③ 新库页若让内容从顶栏下滑过，底色必须 surfaceContainerHighest（亮度比 1.232）， 用 Low 会与栏同色。⇒ 动效做在「库列表 → 主界面」这条导航上，不碰主界面内部的 Tab 转场。
批内容风险
P4-a库身份卡 + 活跃库摘要卡低，纯 UI
