## 一、旧前景层文件头（原文要点，2026-09-16 定稿 V5）

**图形**：徽章盾 + V 带。三层结构自外向内为「白描边盾 →（留一道缝）→ 白色内场 → 金色 V 带」。
描边 + 缝 + 内场 = 徽章 / 珐琅的层次感；V 呼应 Vaultix，盾形本身是 U，即「U 中含 V」；
V 是全图标唯一的第二色相。

**硬约束**：所有内容收进半径 33dp 的安全圆。前景画布 108×108，系统只保证中心 66dp 圆
（半径 33）内可见；圆遮罩切四角、squircle 切得更多。

V5 实测：外盾最远点 **24.64dp**（含 2.82 描边外缘 = **26.05**，距安全圈余量 **6.95dp**）；
内场 19.42、V 带 13.10，均在安全圈内。
历史：V3 余量仅 1.40dp ⇒ V4 整组缩小 12% 得 5.18 ⇒ V5 调整比例后再得 6.95。

### V5（2026-09-16）：把外盾「短一点、稍微胖一点」

用户原话：「当前图标显得很细长，能短一点吗，稍微胖一点，但不要太多」。
V4 外盾 **宽 35.20 / 高 46.64** ⇒ 宽高比 **0.7547**，确实偏细长；盾形常见比例在 0.85 上下。

做法：对全部三层应用同一个绕画布中心 (54,54) 的非均匀缩放

```
x' = 54 + (x-54) × 1.05
y' = 54 + (y-54) × 0.933
```

新比例 **0.8494**（宽 36.96 / 高 43.52），面积仅 −2%（不是变小，是变方）。

为什么这次非均匀缩放是安全的：

1. 变换以对称轴 x=54 为不动点 ⇒ 左右对称构造性成立（实测左右留白差 **0.000000**）；
2. 三层用同一个变换 ⇒ 彼此严格同构，不会出现「内盾与外盾形状不一致 / 漂移」；
3. 唯一副作用是圆角被拉成椭圆（比 1.05 : 0.933 ≈ 1.13:1），对 r≈1.2 的圆角肉眼不可辨。

原注释写着「想再调比例，改 KX/KY 重跑 `build/sign/v5_stretch.py` + `v5_write.py`，不要手改顶点」。
⚠️ **这条现在是死链**：这两个脚本已不存在且不在 git（`build/` 被忽略），
`solve_v3c.py` 同样丢失。这正是本轮重建 `tools/icon/` 的原因。

### 内场必须由外盾「等比缩放 + 平移」生成（本项目最贵的一课）

2026-09-14，issue #89：

- V1：内场是外盾等比 0.78 缩放 ⇒ 形状同构，但缝宽不均（横 2.80 / 顶 4.12，差 47%），
  视觉上读成「盾在往下掉」。
- V2：为让缝宽相等，改为**手工按每条边偏移拼曲线** ⇒
  拼出的 Q 角在纵横方向被非等比拉伸（横占 0.4145 / 纵占 0.1460；
  外盾是 0.3500 / 0.1321）⇒ 左右角不再一致 ⇒
  **内场面积质心横向偏了 −0.29dp**（53.71 vs 外盾 54.00）。用户当场发现「内层的盾和外层的盾没对齐」。
- V3 回到等比缩放（k=0.815，单一缩放比 ⇒ 形状严格同构）；
  V4 再对整组做一次绕质心的统一缩放（外盾 0.88 / 内场与 V 0.85），
  平移使面积质心精确等于外盾质心。实测：内场质心偏差 **0.000541**、V 质心偏差 **0.000180**；
  左右留白差 **0.000000**。

核心认识：外盾是「方肩 + 尖底」，顶边直线、底尖曲线，两种边界的等距偏移性质不同
⇒ **缝宽「四边相等」与「左右对称」几何上不可兼得**。本项目明确选左右对称，
按「最小缝 ≥ 2.0dp」定 k。

V5 缝宽：左 3.93 / 右 3.93 / 顶 4.03 / 底 5.22。四边不等是几何必然，不是缺陷；
取舍是让最小缝（≈1.75dp@48）不至于糊。内场刻意比外盾多缩一点（0.85 vs 0.88）
把缝「挣」回来。

### 其它

- V 带圆角化：48dp 下 V 臂宽仅 2.83dp，直角转折在细笔画上显「脆」，24dp 下易糊成块。
  顶两外角 r=1.2、底尖 r=1.6、内 V 尖 r=1.2。圆角化改变面积分布，必须重新做质心对齐。
- V 的「视觉居中」要算：V 臂在上方、顶部最厚，面积质心天然高于包围盒中心。
  边采样越界 **0/7202**（内场 0/4202）。
- 判「整组是否居中」用**外层图形的面积质心**比画布中心，不能拿内层质心去比；
  按包围盒中心平移会把顶角推出安全圈（r=33.20 > 33）——外盾本来就该略偏下。
- 判据教训：用户说「白条很大」时先量再改；量出来是「24dp 留白 + 渐隐画在空白区」两件事，
  与「栏透明没做」都不是同一回事。

## 二、旧单色层文件头（原文要点）

- 开启「主题图标」后系统**丢掉背景与配色**，只取这一层的形状（alpha），
  再用从壁纸派生的单色重新着色 ⇒ 只能是单一纯色剪影，任何渐变 / 多色都会被压平。
- 与彩色前景的差异：外圈同样描边、内场同样实心；
  **V 带必须改成挖空（洞）**——单色层只有一种着色，填色的 V 会与盾同色而整块消失。
  旧实现用 `fillType="evenOdd"` 挖洞。
- 两层结构可以不同，但**形状语义必须一致**（都是「盾 + V」），
  且内场 path 必须与彩色前景逐字符一致，否则普通图标与主题图标会错位。
- 填充色用白色只是「给个纯色」，实际由系统着色覆盖；换黑也一样。
- XML 注释里不能出现连续两个短横线（解析器硬限制，表格分隔线会直接让解析失败）。

## 三、退役后仍然适用的两条纪律

1. **内层一律由外层「等比缩放（单一 k）+ 平移」生成，禁止手工按边偏移拼曲线。**
   等比 ⇒ 形状严格同构 ⇒ 左右对称构造性成立；非等比会拉伸圆角并让面积质心横向漂移。
2. **视觉居中的判据是面积质心，不是包围盒中心；缝宽四边相等与左右对称不可兼得，
   本项目选左右对称。**

新折纸 V 虽然不再有「内外层」，但「右半由左半镜像生成」「用面积质心核对称」
正是这两条纪律的延续；四条校验已固化在 `tools/icon/generate_launcher_icon.py --report`。
