## 📎 附件功能补全：Bitwarden 与 KeePass 库都能新增 / 下载 / 删除

这一版把附件从「只能看看、只能下载」补全为**双向完整**：Bitwarden 条目和 KeePass（KDBX）库里的附件，现在都能新增、下载打开和删除。附件区同时改为默认折叠，平时不打扰。

- **Bitwarden 附件可上传、可删除**：此前只能在详情页列出和下载服务端已有的附件。现在能直接添加本地文件（写方向加密 + 专用附件端点，走服务端签名上传，不走会被 Bearer 泄露的第三方请求路径），也能删除。附件在本地加密后才上传，服务端只存密文。
- **KeePass（KDBX）附件可导出、可新增删除**：此前 KDBX 条目附件只显示文件名，标注「暂不支持导出」。现在能下载打开，也能新增和删除——写入时按 KeePass 的保真规则只改二进制引用，不动其它字段，删除后清掉无引用的二进制内容（别的条目仍引用的会保留）。可与 KeePassXC 互通。
- **附件区默认折叠**：绝大多数条目没有附件、或你不关心附件，因此平时只显示一行「附件」（有附件时带数量），点开才看到列表和添加入口。折叠状态转屏不丢。
- **单附件上限 100 MB + 提前拦截**：对齐 Bitwarden 官方移动端上传的 100 MB 硬限。选超大文件时先查系统文件大小，**超限直接提示、不再把整份文件读进内存**，低内存机型不会因此卡顿或闪退。
- **敏感数据清理**：锁库、删除条目时会清理附件的明文缓存；所有密钥材料在各条路径（含异常分支）都会清零。

## ⚠️ 升级须知

- 本版不改动数据格式，不需要重新登录、不需要重新注册通行密钥，旧库可直接升级。
- 单附件上限 100 MB（与 Bitwarden 移动端官方口径一致）；KeePass 库文件本身可存更大的附件，但手机端写入是整库重写，建议仍控制在 100 MB 内。
- 附件的新增 / 删除会立即写回：Bitwarden 走专用附件端点、KDBX 走库写入；新增后经同步流刷新列表，不要手工改同一份条目。
- 从旧版升级后，既有附件（无论 Bitwarden 还是 KDBX）均可正常下载打开，无需重新添加。
