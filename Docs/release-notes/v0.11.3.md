## 🔐 KDBX 写回：把「改了却传不上去」这条链修通

上一版之后暴露出来的一串问题，根因各不相同，但表现都是「手机上改了，电脑的 KeePassXC 看不到」：

| 现象 | 根因 |
|---|---|
| 删条目 / 删文件夹 / 换文件夹后，云端文件不变 | 写回基线闸门在会话重开后判成「未对齐」直接拒写 |
| 「已同步」状态下反而永远保存不了 | 同一把闸门的两份状态互相打架，形成死锁 |
| 改动偶尔上传成功、偶尔永远不传 | 上传失败后没有重试，一次网络抖动就丢 |

这一版把闸门改成「**只有远端真的变过才拦**」，本机内部状态漂移会被自动放行；上传失败按 3s → 8s → 20s 退避重试；落盘失败会回滚会话，不会留下"界面改了、文件没改"的中间态。

## ⚡ 删、改、恢复：点完就走

- 删除条目 / 文件夹、从回收站恢复，**点下即刻生效**，不再整页转圈等同步。
- 上传完全后台化：本地落缓存就算完成，云端在背后传，失败会自己重试。
- 回收站不再整页变灰，只有被点的那一条在忙。
- **上传失败、两端都改了、云端有新版本**——这三种情况现在会在列表顶部挂一条常驻提示，带「重试」；平时上传中只在 ⋮ 上点一颗小圆点，不占地方也不打扰。
- 点进条目时那一帧多余的转圈去掉了：根因是数据流里有一行 `.onStart { emit(null) }`，让首帧走错查询分支（KDBX 库去查了 Bitwarden 的表），绕了一圈才回来。

## 🎛 菜单与设置：按 Material 3 重排

- **锁定按钮挪到菜单右下角**，不再占一整行 —— 它是低频动作，整行可点时拇指从下往上扫很容易误触。
- 条目页 ⋮ 里的「同步」只在真出问题时出现：它和下拉刷新本来就是同一个动作，同一个屏放两个按钮只会让人犹豫。
- **设置 → 密码库管理**：每行行尾直接给「同步」，不用再点开三个点；星标「设为默认库」降级成副标题里的「默认库」三个字，设置入口收进 ⋮。
- 设置页的图标改为**对齐标题行**（此前随副标题行数上下跳），防截屏关闭态那句后果说明不再被截断，组名「密码库与解锁」改为「密码库与安全」（组里其实有防截屏、剪贴板、权限三项与解锁无关）。

## 📄 详情页：长条目不再铺满一屏

- **网址超过 3 条折叠**，其余收进「另外 N 个网址」，展开状态在转屏后保留。
- **创建 / 修改时间降级成页脚一行小字**：`创建于 X · 修改于 Y`，不再占一张卡片和一个分区标题 —— 它是整页信息价值最低的内容，位置应该留给 2FA 和备注。

## 🐛 其它修复

- 长表单滚动时底部「保存 / 取消」跟着漂移错位。
- 全屏表单顶部的 ✕ 去掉（底部已有取消，两处入口反而误触）。
- 密码高亮配色、TOTP 码规格、动作条对齐统一。
- 文件夹删除的闪退防线。

## ⚠️ 升级须知

- 覆盖安装即可，**数据与指纹 / PIN 锁保持有效**，无需卸载重装；签名沿用同一固定密钥。
- 首次进入某个 KDBX 库时若提示「需要重新解锁后重试」，点一次重试即可收敛（这是写回基线在重新对账，只需一次）。
- 安装后建议用发布页的 SHA-256 清单核对 APK。
