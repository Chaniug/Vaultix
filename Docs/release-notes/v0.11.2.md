## ✨ 液态玻璃底栏：从「磨砂板」到真玻璃

底栏原本只有背景模糊 + 半透明填充，边缘没有光，看起来更像一块塑料板。这一版补上**光学层**：

| 效果 | 说明 |
|---|---|
| 边缘折射 | 沿胶囊轮廓把背后内容轻微推挤，越靠边越明显 |
| RGB 分色 | 边缘极轻微的红蓝错位，模拟玻璃色散 |
| rim 暗线 + 上下沿高光 | 让胶囊从背景上「切」出来，而不是浮在上面 |
| 三档降级 | Android 13+ 完整效果；12 / 12L 保留模糊；更早版本回到实心底栏 |

实现上让 AGSL 直接采样图层内容、与模糊串成一条渲染链，**不需要每帧把画面读回内存**。点击动效这一版刻意没做，保持原来的克制。

## 🪟 弹窗与按钮：一套规格，不再各写各的

- 弹窗从「写死八成屏高」改成**按内容收缩 + 上限**，短确认框不再是一大块空白。
- 「保存 / 取消 / 继续 / 返回」统一为 M3 的填充主按钮 + 轮廓次按钮；危险操作保留独立配色。
- 三个按钮挤一行会把主按钮挤出屏幕（修改 PIN 时「继续」只剩一条竖条）——动作区改为**可换行**，任何字号都不裁切。
- 「添加密码库」卡片收小、副标题精简为一行，第三项不再被截；三种来源用**图标底色**区分，卡片本身保持统一。
- 网盘账号页的卡片与下方表单对齐到同一档边距。

## 🐛 修复

- **「进入 App 时仍需验证」开关闪一下才停**：数据没读出时先显示「开」、写入又是异步的，受控开关会回弹一次。现在改为「未读出显示占位、点下立即上屏、落盘后确认」。
- 设置页两处长文本说明弹框补上滚动，大字号 / 小屏不再截尾。
- 「修改 PIN 完成」结果框补了状态图标；弹窗标题与输入框标签的字号层级不再倒挂。
- 修掉卡住 CI 的 detekt 门禁问题，本版完整跑过 1637 例单测、0 失败。

## ⚠️ 升级须知

- 覆盖安装即可，**数据与指纹 / PIN 锁保持有效**，无需卸载重装；签名沿用同一固定密钥。
- 折射效果需要 Android 13（API 33）及以上；更低版本自动退回模糊或实色底栏，**功能不受影响**。
- 安装后建议用发布页的 SHA-256 清单核对 APK。
