## 🛡 正式版不再写调试日志

- 此前有 8 处日志绕过统一的日志开关，装的是**正式版**也照样往系统日志里写调试信息，其中一条还带完整库标识。现在全部收敛到统一门面：正式版默认不输出、库标识经脱敏；调试版日志行为不变。
- 新增构建期红线：正式源码里再出现裸日志或 `!!` 空值断言，CI 直接判红，防止以后改回去。

## 🧩 消除潜在闪退点

- 通行密钥创建、断言签名、网盘 KDBX 同步三处，此前对可空值直接用 `!!`，极端情况下（页面在写入途中被销毁、远端来源为空等）可能空指针闪退。现改为「先取快照、空值有明确去向」，并顺带修掉同步时文件源被构造两次的隐患。

## 📦 预览包名字更短

- 开发预览包 APK 名由 `Vaultix-v0.13.1-dev-xxxxxxxx-preview.apk` 缩成 `Vaultix-xxxxxxx.apk`，Release 标题去掉冗余前缀。**正式版包名不变**，版本号仍是稳定版唯一标识；预览包的版本 / 提交 / 构建 / 签名四项信息完整保留在 Release 页。

> 本版为安全与工程质量维护版本，未新增功能；v0.13.1 已发布坚果云 WebDAV 403、网盘账号注销闪退等真机修复。
