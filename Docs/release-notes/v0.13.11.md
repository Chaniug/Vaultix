## 🛡️ 快速解锁密钥加固与自动填充稳定性

这一版加固了指纹解锁的密钥失效机制，并修复了自动填充响应在后台线程组装的隐患。建议所有用户升级。

- **指纹解锁密钥随指纹变更立即失效**：此前部分国产系统（OEM）不遵守 Android 密钥默认行为，导致新增指纹后，旧指纹仍可能解开快速解锁密钥。现在显式绑定「生物识别登记变更即失效」——增删指纹后，旧密钥立即作废，需用主密码重新解锁一次并建立新的快速解锁，防止他人在你设备录入指纹后绕过验证。
- **自动填充响应改在主线程组装**：此前 Dataset / FillResponse 在后台线程构造，违反 Android 框架约定，国产 ROM 上有偶发填充面板异常的风险。现在对象组装统一回到主线程，图标读取仍留在后台、不拖慢填充。真机验证：填充照常、系统主线程警告消失。
- **夸克等浏览器兼容性诊断增强**：补齐夸克浏览器的自动填充兼容名单，并对无法识别的输入框增加脱敏诊断日志。需说明：夸克采用自绘内核，不向系统上报标准可填字段，实测 Bitwarden 同样无法在其上填充——这属浏览器内核限制，非 Vaultix 缺陷；Chrome / Edge 正常。

## ⚠️ 升级须知

- 本版不改动数据格式，不需要重新登录、不需要重新注册通行密钥，旧库可直接升级。
- 如果你此后**新增或删除过系统指纹**，首次打开可能需要用主密码解锁一次以重建快速解锁密钥——这是上面第一条加固的预期行为，不是数据丢失。
- 自动填充的候选匹配、认证、验证码复制逻辑均未改动；「从不锁定」档位的免交互行为保持不变。
