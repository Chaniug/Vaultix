## 🎨 条目页 ⋮ 菜单焕新 + 卡包钱包堆叠

这一版把条目页的「⋮」菜单重做成 Material 3 Expressive 分组卡片，修掉了点菜单直接闪退的问题，
并给卡包加上「收拢成一摞卡 / 展开平铺」的视图切换。同步提示与筛选动画也做了轻量打磨。

- **卡包新增收拢视图**：顶栏新增视图切换按钮，点一下把卡片收成一摞「钱包」（错层 + 轻微旋转 +
  顶层投影），再点展开回原来的平铺。状态会被记住，切 Tab / 旋转屏幕不丢。收拢态只做静态堆叠、
  不做翻转动画；长按选中与左滑删除仍只在展开态生效，避免误触。搜索时强制平铺，不藏卡片。
- **同步提示更克制**：同步进行中的 240×10dp 波浪粗条换成满宽 3dp 扫光细条，只在顶栏下方轻轻扫过，
  不再占据大块横幅。
- **筛选展开更顺**：点库名展开快捷筛选时，各 chip 从左到右依次淡入（30ms 递进），像铺开而非整排蹦出。
  面板高度与列表让位仍逐帧同步，不会压住第一条条目。

## 🧩 条目页 ⋮ 菜单：三块 Expressive 分组卡片

原来是一整块老式 DropdownMenu：4dp 圆角、组间只靠 1dp 横线、组标签是灰色小字，功能没少但观感老套。

- 换成 M3 Expressive 分组卡片：库身份 / 导航四项 / 同步锁定行三组，16dp 全圆角 + 8dp 间隙 + 描边，
  浅色下也不会糊成一片。
- 补上 40dp 库类型徽标；去掉冗余的「前往」小标题。

## 🛠 修复

- **点 ⋮ 直接闪退**：#301 改版后，菜单首开会在测量阶段抛异常（分组里的中间省略文本用了不支持
  intrinsic 测量的组件，而 M3 菜单会向子树索取 intrinsic 宽度）。已改用适配 intrinsic 的变体，
  菜单正常弹出，同时保留长路径的中间省略。
- **自动锁定时长「天」显示错误**：自定义时长先判小时再判天，而 1440 分钟 = 24 小时，导致选「1 天」
  显示成「24 小时」。已修正判定顺序并补单测。

## 💡 状态灯五态五色

菜单里的同步状态灯重新规范：上传中从同步中的琥珀拆成蓝色，冲突态改为警示橙，并要求只画一次
（收拢在身份带），避免同一状态在菜单里出现多处。

## ⚠️ 升级须知

- 本版不改动数据格式，不需要重新登录、不需要重新注册通行密钥，旧库直接可用。
- 卡包收拢只是视图切换，不影响卡片数据；展开态的删除方式（长按选中 → 左滑 → 二次确认）不变。
