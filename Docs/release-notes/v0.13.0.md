- 全站换用新版「折纸 V」品牌图标。

## 🔀 转场

- 设置二级页改走 **Material 3 官方 Shared Axis X**（`slideIntoContainer` / `slideOutOfContainer`，进入 300ms、退出 200ms，位移用 API 默认的 1/4 视差），取代此前自创的轻位移参数；Tab 切换保持原有轻量淡入。
- 这一项是两轮真机取证后的收口：原来的「过渡不自然」不是掉帧，而是几乎无过渡；加上转场后又暴露出两页同时布局的开销，最终按官方参数定案，且**完全不做 alpha**，规避深色模式漏背景闪烁。

## 🔐 同步与数据可靠性

- **#287** 改完 KDBX 条目立刻返回不再丢改动 —— 写回协程原本跑在 `viewModelScope`，页面返回会把它取消在 KDF 自检的几秒窗口内；现在八个写动作统一收口在 `serialWrite` 的 `NonCancellable`，脏缓存也提到自检之前先落。
- **#286** KDBX 改动不再被刷新覆盖，冷启动 / 解锁补传闭环。
- 修复 KDBX 通行密钥写入丢字段。
