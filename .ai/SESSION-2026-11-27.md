## ★ 关键技术发现（推翻旧结论）

1. **kotpass 0.13.0 有公开 binary API**：`KeePassDatabase.binaries` / `modifyBinaries{}` /
   `removeUnusedBinaries()` / `BinaryData.getContent()` 全部 public；Maven 最新版就是 0.13.0
   （2025-09-28，项目已在此版本）。KDBX 附件**无需升版、无需反射**即可读写。
   `KdbxItemMapper.kt:200-225` 的「只能反射」注释已过时，实施时须订正。
2. **Bitwarden 上传协议清晰**：`POST /ciphers/{id}/attachment/v2` 拿 URL +
   `fileUploadType` 0=Azure PUT / 1=Direct Multipart；删除 `DELETE .../attachment/{aid}`。
   bastion 有完整参考（GPL 同源合法），Vaultix 加密基元（`SymmetricCryptoKey.random()`、
   `VaultixCrypto.encrypt()`）齐备，缺附件格式写封装 + API + 编排 + UI。
3. **附件不进普通写回**：`CipherMapper` 明确附件刻意不透传（服务端整体替换语义），
   上传/删除必须走专用端点，用 `cipherResponse` 更新本地列表。
