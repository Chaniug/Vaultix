## 277. 液态玻璃底栏「点击效果 / 玻璃效果没做完善」+ 注意边界和大小（2026-11-10 深夜，用户反馈）

**用户原话**：

> 把液态玻璃底栏做好吧。目前点击效果和玻璃的效果都没有做完善。注意底栏的边界和大小。可以参考优秀的项目是如何实现液态玻璃底栏的。

三个症状收敛到三处各自独立的缺陷，第四点「边界和大小」是**约束**不是症状 ——
它反过来限定了前两处不许怎么改。前一轮（#198/#200/#205）已经把「源 → 效果层 → 消费」
的架构和三档降级定死，本轮**不重构链路**，只补观感层。

### 一、边界：高光与描边断在圆角（用户点名的「边界」）

`drawGlass` 旧版用 `drawRect` 画四种几何：填充、上沿渐隐高光带、1dp 顶亮线、矩形内描边
（外加底部矩形暗线）。层 B 外面虽然 `.clip(Pill)`，但**被裁掉的正是药丸两端的半圆** ⇒
圆角处既没高光也没描边，真机上读作「上下有边、左右没边」的一块板。

改法：所有几何一律按 `Shape.createOutline(size, layoutDirection, density)` 生成的
`Outline` 用 `drawOutline` 画，圆角连续。五层分工（都走同一个 `outline`）：

| 层 | 内容 | 为什么 |
|---|---|---|
| ① 填充 | 竖向渐变（真模糊档上亮下暗做厚度；降级档纯实色） | 降级档做渐变=两块塑料 |
| ② 高光带 | 顶部渐隐 `Brush.verticalGradient` | 靠 gradient 自己衰减，不需要 `clipRect` |
| ③ 镜面 rim | 整圈 `Stroke`，垂直渐变「上亮 → 侧淡 → 下沿暗」 | 合并旧的 1dp 亮线 + 底部暗线，圆角不再断 |
| ④ 焦点高光 | 按住时径向渐变 `Stroke`，光源落在被按 tab 上沿 | 按压联动（见三） |
| ⑤ 内描边 | 一圈弱 `Stroke` | 与背后内容分界，不是打光 |

⚠️ **降级档（`blurAvailable = false`）只画 ① 与 ⑤ 后 `return`**：实色板再叠镜面/暗线
会变成两道塑料描边。这条 `if` 旧版就有，重构时不能丢（有文本门禁钉住）。

⚠️ `drawOutline` 在 `androidx.compose.ui.graphics`（`OutlineKt`），
**不在** `androidx.compose.ui.graphics.drawscope` —— 第一版 import 错包编译不过，用 `javap` 查到才改对。

### 二、玻璃效果：模糊把彩色内容洗成灰雾

只做 `blur` 时，背后彩色条目被糊成一片中性灰，看起来像蒙了层雾而不是玻璃。
参考实现口径一致：Haze 的 vibrancy、PrismalAGSL 的 saturation、LiquidGlassBar 的 1.5×
都在模糊之后补一道饱和度增强。

- `LiquidGlass.SATURATION = 1.38f`（>1 且 ≤1.6，防过曝，有数值单测）；
- `saturatedBlur()` 用 `ColorMatrix.setSaturation` + `createColorFilterEffect`，
  以 `createChainEffect(saturation, blur)` 串在模糊之后 —— **outer 作用于 inner 结果**，
  所以饱和度必须是第一个参数，写反了不报错、只是没效果；
- 31–32 的 `plain` 和 33+ 的 AGSL 内层**都接 `saturated`**（文本门禁钉「覆盖所有有模糊的档位」）；
- ⚠️ **不改 AGSL 源码**：AGSL 是运行时编译、CI 覆盖不到，改它的风险与收益不对等；
  用 ColorFilter 链顺带让 31-32 也拿到 vibrancy。链路失败 `runCatching` 原样返回 blur
  （饱和度是增益不是前提）。

### 三、点击效果：按压只发生在 item 内部，玻璃本体毫无反应

旧版按压缩放 / 图标弹跳 / pill 换色都只在**被按的那一个 item 内**，`LiquidGlassLayer` 一无所知。
把「有没有在按、按在哪个槽」折算成 `GlassPress(intensity, focusX)` 两个**纯绘制参数**上报：

- `intensity` → 镜面 rim 增亮（`PRESS_SHEEN_GAIN`）、AGSL 折射变深（`PRESS_REFRACTION_GAIN`，`uDepth` 乘 `1 + 0.35·intensity`）；
- `focusX` → 焦点高光落在被按 tab 上沿；5 个等分槽用 `dockSlotFocus(slot) = (slot+0.5)/5`，
  松手 `dockIdleFocus()` 回正中（正好是中央「+」）；
- `DockRow` / `AddButton` / `DockTabItem` 通过 `interactionSource.interactions` 的
  `Press` / `Release` / `Cancel` 上报，`key(item)` 保证不扩散到兄弟节点，选中色仍瞬切；
- 触觉 `HapticFeedbackType.ContextClick` 放在 **`onClick` 松手确认**时，不在 Press 时 ——
  否则长按后取消也会震一下。

⚠️ **性能坑（本轮最贵的一处）**：第一版用 `by animateFloatAsState(...)`，动画值在**组合期**读，
spring 每帧会重组整条底栏（5 个 tab 各自还有 `animateFloatAsState`），按压那 200ms 最容易掉帧。
改成保留 `State<Float>` + `remember { derivedStateOf { GlassPress(...) } }`，
`LiquidGlassLayer` 只收 `State<GlassPress>`，仅在 `drawBehind` / `drawWithContent` 的
**绘制阶段**读 `.value` ⇒ 动画期间 Compose 只 invalidate 绘制、**零重组**。

### 四、约束：边界与大小全程不变（用户特意提醒的那一项）

- `GlassPress` 只改颜色 alpha / shader uniform / 径向渐变中心，**不碰任何
  `size / height / width / padding / aspectRatio`**。文本门禁 `按压联动只进绘制参数_不许改变边界与大小`
  扫描按压相关函数体，出现尺寸调用即判红；
- 玻璃态与实色态**共用同一份 `DockRow` 与 `VaultixCorner.Pill`**，玻璃层不写死高度
  （层 B 只 `fillMaxWidth()`，高度由 content 测量）—— 这是 #205「底栏高度塌 0」之后定下的硬边界：
  **观感状态不许参与测量**；
- 规格：胶囊 60dp 高、左右 12dp、上 6dp、下 20dp（占位 86dp）、圆角 = 高度/2。

### 参考的优秀实现（本轮对齐的口径，非照抄）

| 项目 | 采纳的判据 |
|---|---|
| Apple iOS 26 HIG | 玻璃只属于浮在内容之上的控件层；边缘折射 + **沿轮廓**的镜面高光，内容层保持不透明 |
| chrisbanes/Haze | 源 / 效果 / 消费分离；material 的 alpha 深色更实；无模糊平台降级 flat scrim |
| styropyr0/PrismalAGSL | 三档降级（frost / blur / AGSL）、圆角矩形 SDF 折射、specular + depth inset、按压 spring + 触觉 |
| wzhdgithub/LiquidGlassBar | 模糊后 vibrancy ≈1.5 的饱和度增强、色散、按下放大镜 |
| Kyant0/AndroidLiquidGlass | provider 与 glass 必须**兄弟节点**，不能嵌套（本项目 10-28 白屏事故的同款结论） |

⚠️ **与 8.4-part3 那条「iOS 26 透镜折射 ❌ 有意不做」不冲突**：那条否的是
「可拖动放大镜 / 把背景当纹理喂 AGSL + `PixelCopy` 逐帧回读」这条路径（滚动帧率打穿）。
本项目既有 `OpticsShader` 用的是 `createRuntimeShaderEffect` —— `uniform shader content`
**直接采样 RenderNode 内容**，全程留在 GPU、不回读，做的是**固定沿边缘**的 SDF 折射/分色，
不是可拖动透镜。本轮没动这条链路，只在它前面补了饱和度。

**刻意不做**：陀螺仪驱动光源（传感器 + 每帧更新，收益不抵耗电）、可拖动 lens / goo 融合 /
页面转场（与 #87「不要花哨动效」冲突，11-07 已明确搁置且本轮未解禁）、`PixelCopy` 逐帧回读
（10-27 已证伪）、改 AGSL 源码提饱和度、给玻璃态单写一份尺寸。

### 本轮踩到的坑

1. `drawOutline` 在 `androidx.compose.ui.graphics`，不是 `drawscope`（见一）。
2. `ColorMatrix` 的方法是 **`setSaturation(float)`**，不是 `setToSaturation` —— 第一版凭印象写错，
   `javap` 核对 `android.graphics.ColorMatrix` 后改正。
3. spring 动画值在组合期读会每帧重组整条底栏（见三）⇒ 收 `State`、绘制阶段读。
4. `createChainEffect(outer, inner)` 的 outer 作用于 **inner 的结果**，饱和度链别写反。
5. 文本门禁必须 `stripComments`：`drawGlass` 的 KDoc 里举了 `drawRect(...)` 作反例，
   不剥注释会把它当成真实调用判红（与 #275 同款坑）。
6. Haze 口径「深色 material alpha 更实」在预览里也要落地，不能只做浅色一套。
