## #303 Keystore 故障清理边界

用户要求修复审查发现的 Keystore 暂时故障误删问题，并跟踪 GitHub Actions。

- 指纹门锁解封由 Boolean 改为 `FingerprintUnlockResult`，暂时故障不再进入降级；永久不可解仍按房钥匙内存态执行 rearm/degrade。
- 自动恢复解封由可空明文改为 `AutoUnlockDecryptResult`，暂时故障保留 `house_lock_auto`，永久失效或损坏才删除。
- `UnrecoverableKeyException` 改为可重试；永久失效只认异常链中的 `KeyPermanentlyInvalidatedException`，密文损坏仍认 `AEADBadTagException`。
- 新增暂时故障保留、永久失效清理等回归测试。两条旧实现红灯均由断言确认，非编译失败。
- 本地验证：`HouseKeyStoreTest` 24 例、`LocalUnlockFailureTest` 14 例、`data/repository` 358 例全绿；全套静态门禁与 `diff --check` 通过。
- 本地没有 Android SDK 环境文件，app 的 Compose 编译和完整单测交由 GitHub Actions。

详见 `issues/04-锁与解锁-part10.md` #303。仅开发 `main`，未合入 `rele`。
