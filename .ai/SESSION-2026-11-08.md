# SESSION-2026-11-08 · 全屏表单顶部 ✕ 关闭按钮移除

> 主线索见 [`README.md`](./README.md) 顶部状态块。本篇只记这一批，不复述 11-07。
> 约定正文：[`conventions/8.4-UI·观感.md`](./conventions/8.4-UI·观感.md)（顶栏 / 一屏两套规格）。

## 0. 一句话结论

用户提出「新建条目页左上角的 ✕ 可以不用，现在都是系统操作返回」→ 从共用壳
`FullScreenDialogShell.TitleBar` 里删掉 `IconButton(Icons.Filled.Close)`，
**三个页面（新建 / 编辑条目、添加 / 编辑验证码）统一生效**；关闭逻辑与判脏闸门一行未改。

## 1. 现象 / 需求

- 用户截图：`items_new_item`（新建条目）页，左上角 ✕ 与底部「取消」并存。
- 用户原话：「新建条目的时候，左边×关闭符号可以不用吧，现在都是系统操作返回，
  很少点击那个关闭按钮。」
- 真实诉求是**去掉一个冗余的关闭入口**，不是改关闭行为、不是加返回拦截。

## 2. 根因 / 约束（为什么只能这样改）

✕ 不在 `ItemFormDialog` 里，而在**共用全屏编辑壳**上。该壳共 3 处调用：

| 调用点 | 页面 |
|---|---|
| `ui/common/ItemFormDialog.kt:205` | 新建 / 编辑条目 |
| `ui/totp/TotpCodesScreen.kt:1397` | 添加 / 编辑验证码 |
| `ui/common/FullScreenDialogShell.kt:230` | 壳自身定义 |

- `onDismiss` 同时服务四条路径：顶部 ✕ / 系统返回 / 点外部 / 底栏「取消」，
  且调用点都接 `rememberDiscardGate`（2026-11-05 的「放弃未保存修改」判脏确认框）。
  ⇒ **删 ✕ 不丢功能、不丢确认框**，剩三条仍共用同一个 `onDismiss`。
- 用户给的理由（系统返回已够）对三页同等成立；全局删改动最小、观感一致。
- **没有给壳加「是否显示 ✕」开关参数**：壳已有 7 个参数、贴着 detekt
  `LongParameterList` 上限（`FullScreenDialogShell.kt` 的 `DiscardChangesDialog` KDoc
  明确记着这条），且分叉会让「新建无 ✕ / 编辑有 ✕」变成一屏两套规格
  —— 正是 `8.4` 反复在防的漂移。用户已拍板「全部去掉」。

## 3. 做法（改了什么，文件:行）

单文件：`app/.../ui/common/FullScreenDialogShell.kt`，19 增 19 删。

1. `TitleBar`（原 513–518 行）删掉 `IconButton` + `Icon(Icons.Filled.Close)`，
   并去掉 `TitleBar` 的 `onDismiss` 参数与调用处实参（壳的 `onDismiss` 仍被
   `Dialog.onDismissRequest` 与 `ActionBar` 使用，保留）。
2. 标题 `Row` 加 `.padding(horizontal = Spacing.xl)`（24dp）：删掉 ✕ 后
   标题不能贴屏幕边，起点要对齐正文卡片（正文 `Column` 是 `horizontal = Spacing.xl`）
   与底栏按钮（11-07 刚统一到 24dp）。
3. **`TITLE_BAR_HEIGHT = 56dp` 刻意不变**。它原是「`IconButton` 48dp 触摸目标 +
   `BAR_VERTICAL_PADDING`×2」，现在顶栏只剩 `Text`，但 ① 与底栏 `ACTION_BAR_HEIGHT`
   同档；② 是 `contentClearance` 让位公式的入参，改了就重现第一轮
   「正文首元素被不透明栏遮住」；③ 标题靠 `verticalAlignment = CenterVertically`
   在 56dp 里居中，节奏稳定。**改高度是这次最诱人也最错的「顺手优化」**。
4. 清理 4 个失效 import（`Icons` / `Close` / `Icon` / `IconButton`）。
5. 同步 KDoc：布局契约「标题 + 关闭」→「仅标题」；`@param onDismiss` 三条路径；
   判脏闸门段「四条路径」→ 注明 11-08 前含 ✕、现三条；`TITLE_BAR_HEIGHT` 补上
   上面第 3 点的取舍，避免后人照旧注释去缩高度。
