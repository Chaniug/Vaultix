## 1. 用户反馈

「在密码条目界面滑动的时候，点击进入密码条目，会发现有一个一闪而过，**1 帧都不到**的提示：
*此条目不存在或已删除*。」

## 2. 排查路径（含一条被证伪的假设）

| 步 | 假设 | 结论 |
|---|---|---|
| 1 | 文案是 `R.string.detail_missing`，全仓只有 `ItemDetailScreen.DetailBodyContent` 在用 | 成立 |
| 2 | 该分支条件 `item == null`，而 `UiState.item` 初值就是 `null` | ✅ **真根因** |
| 3 | 怀疑 `ItemRepositoryImpl.observeItem` 的 `vaultDao.observeAll()`（Room 流先跑一次查询）把 `cipherDao.observe()` 卡在 `flatMapLatest` 上游 | ❌ **实测证伪**（见下） |

**证伪过程**：写一个最小探针（`vaultDao.observeAll()` 延迟 200 ms 才发首值），
分别在有/无 `.onStart { emit(null) }` 两种实现下跑 `observeItem(...).first()`——
**两次都拿到 `GitHub`**。原因是 `runTest` 的虚拟时钟会把上游 `delay` 推进掉，
"Room 首查耗时"在 JVM 单测里根本不会被模拟出来。⇒ 数据层首值不是本 bug 的成因。

> 🔴 **判据：先证伪，再改。** 一条"看起来完全合理"的链路（上游未发射 ⇒ 下游不订阅）
> 也可能与现象无关；照直觉改，会把一个**没修好任何东西**的改动混进修复提交。

## 3. 修复（两层，缺一不可）

| 层 | 文件 | 改动 |
|---|---|---|
| 状态 | `ui/detail/ItemDetailViewModel.kt` | `UiState` 新增 `itemLoaded`；`observeItem` 收集到首个发射即置真，**永不回落** |
| 呈现 | `ui/detail/ItemDetailScreen.kt` | `DetailBodyContent` 新增 `loading`；`loading && item == null` 画波浪转圈，`item == null` 才画缺失提示 |
| 数据（保留） | `data/repository/ItemRepositoryImpl.kt` | `observeItem` 加 `.onStart { emit(null) }`：让下游**立刻**订阅条目行流（前置订阅的廉价优化，**非**本 bug 修复点，KDoc 已如实写明）|
| 测试 | `ItemRepositoryImplTest` | 新增 `observeItem_firstEmissionIsNeverNullOrBeforeVaultKindResolves` |

### 判据（写进 MEMORY §9 与 issues/06 #181）

> **「未知」必须是一种显式状态，不能借用「空值」来表达。**
> `null` 同时表示"没有"和"不知道"时，UI 必然在其中一种情况下撒谎。

## 5. 沙箱环境补齐（下次接力可直接用）

本轮把"能在沙箱里真编译 + 真跑单测"补齐了，代价与做法记在这里：

| 卡点 | 做法 |
|---|---|
| JDK 17 | `apt-get install openjdk-17-jdk-headless`（沙箱默认是 JDK 20，AGP 不接受）|
| Gradle 9.5.1 下载超时 | 走腾讯镜像 `mirrors.cloud.tencent.com/gradle/gradle-9.5.1-bin.zip`，解包后放进 `~/.gradle/wrapper/dists/gradle-9.5.1-bin/<hash>/` 并 touch `.ok` 文件 |
| `~/.gradle/init.gradle` 语法错（`url https://…` / `mavelCentral()`） | 重写成 `beforeSettings` 里**前置**插腾讯云镜像；⚠️ 不能 `allprojects { repositories { … } }`——项目设了 `FAIL_ON_PROJECT_REPOS` |
| `common4j-24.6.0.jar` 找不到 | 镜像 pom 命中但 jar 缺失（Duo feed 404、镜像 200）⇒ `--refresh-dependencies` 重新解析即恢复 |
| `platforms;android-37` 不存在 | 实际包名是 **`platforms;android-37.0`**（与 `ensure-android-sdk.sh` 的前缀匹配一致）|
| 任务名 | 普通 Android library 模块是 `:data:repository:testDebugUnitTest`，**不是** `testFullDebugUnitTest`（后者是 `:app` 的 flavor 任务）|
