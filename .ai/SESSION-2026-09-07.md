## 踩坑记录：Git Bash 与原生 git 的路径映射错位
- **现象**
  - Bash 中执行 `git clone ... /tmp/xxx`：打印 `Cloning into...` 且退出码 0，但随后 `ls /tmp/xxx` 报不存在
  - Bash 中执行 `git clone ... /d/Vaultix`：误报 `destination path already exists and is not an empty directory`，而该目录实际为空
- **根因**：MSYS/Git Bash 与原生 Windows git 对 `/tmp`、`/d/` 的解析不一致。传给 git 的 `/tmp/xxx` 被落成 `D:\tmp\xxx`，而 Bash 的 `/tmp` 指向 Windows Temp，两边对不上；对 `/d/Vaultix` 的"非空"判断也同样失真
- **解决**：改用 **PowerShell + 原生 Windows 路径**（如 `D:\Vaultix`）执行 git clone，一次成功
- **教训**：本环境涉及 git 的目录写入操作时，优先用 PowerShell 与 `盘符:\路径`，不要依赖 Bash 的 `/tmp`、`/d/` 形式

**AGP 9 迁移踩坑（逐条实测）**：
1. **禁止 apply `kotlin-android`**：AGP 9 内置 Kotlin，显式 apply 会报 `Cannot add extension with name 'kotlin'`。所有模块已移除该插件。
2. **`kotlinOptions` 已废弃**：改用顶层 `kotlin { compilerOptions { jvmTarget = JvmTarget.JVM_17 } }`，且必须用 `JvmTarget` 枚举而非 `JavaVersion`。
3. **catalog 别名不能叫 `kotlin-jvm`**：Gradle 9 的 plugins 块中 `kotlin` 前缀会与内置 `kotlin {}` DSL 撞名，`libs.plugins.kotlin.jvm` 被误解析为 `ToolchainManagement.jvm`。改用别名 `kgp`（仅根工程 apply false，用于把 KGP 带上 classpath 以统一多模块 Kotlin 版本）。
4. **类型安全项目访问器需显式启用**：`settings.gradle.kts` 加 `enableFeaturePreview("TYPESAFE_PROJECT_ACCESSORS")`，否则 `projects.core.model` 被解析成 `TaskContainer.projects`。
5. **Hilt 与 AGP 9 / Kotlin 双重绑定**（关键）：
   - Hilt < 2.59 在 AGP 9 下抛 `Android BaseExtension not found`（旧 DSL 已被 newDsl 移除）
   - Hilt 与 Kotlin 强绑定：Kotlin 2.4.x → Hilt **2.60.1**；Kotlin 2.3.x → Hilt 2.59.x
   - 实测 Kotlin 2.4.10 + Hilt 2.59 报 `Provided Metadata instance has version 2.4.0, while maximum supported version is 2.3.0`（Hilt 内置 kotlin-metadata-jvm 上限）
   - ⚠️ Bastion 注释称「升 Kotlin 2.4 被 KSP 阻塞」已过时，真正在卡的是 Hilt

## 新建 Docs/16-性能与交互规范.md
用户明确需求：APP 高效、Android 17 流畅、省电、切换舒服、易维护升级、**不要出现超大函数超过 JIT 限制**。
核心内容：
- **代码规模硬上限**：单文件 ≤1200 行（建议 600）、单函数 ≤150 行（建议 60）、单类函数 ≤40、参数 ≤8
- **为什么**：DEX 单方法硬限 65536 code units；ART JIT 对过大方法**不予编译**，走解释执行 → 这是"函数超大导致卡顿"的真正原因
- 反例（Bastion）：`KeePassKdbxService.kt` 6708 行、`BitwardenSyncService.kt` 2594 行
- 性能：`LazyColumn`+稳定 key、列表只持密文句柄、KDF 必须走注入 dispatcher、WorkManager 周期同步
- 省电：禁止常驻轮询、release 零日志
- 交互基线（源自用户亲手打磨的 Bastion 体验）：**顶部大标题随滚动缩放**、**功能折叠进标题**、**沉浸式半透明**、切换顺滑；要求由滚动位置驱动而非定时器
- 门禁：Detekt 启用 LongMethod / TooManyFunctions / LongParameterList / LargeClass
