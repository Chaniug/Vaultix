```

adb shell dumpsys window windows

#   ty=BASE_APPLICATION → Activity；ty=APPLICATION + fl=DIM_BEHIND → Dialog
#   apr=LIGHT_STATUS_BARS LIGHT_NAVIGATION_BARS  → 深色图标（对）
#   apr 整行缺失                                  → 浅色图标（错）
```

修复前：对话框窗口**连 `apr=` 这一行都没有**（⇒ 那段逻辑一次都没跑）。
修复后：`apr=LIGHT_STATUS_BARS LIGHT_NAVIGATION_BARS` 出现，与 Activity 一致。

⚠️ 教训：`?: return@Effect` 这种"拿不到就静默返回"会把整段功能变成**不报错的死代码**。

## 2. 通行密钥注册：两层解析者，缺一不可

见 `issues/03` **#108**（RP 层）与 **#109**（浏览器层）。摘要：

| 层 | 谁在解析 | 失败表现 | 条目 |
|---|---|---|---|
| **浏览器** | Chromium `fido2credentialrequest_native_android.cc` → Mojo | `MojoClassFromJSON … field missing or invalid: publicKeyAlgorithm`，**整份响应丢弃** | #109 |
| **RP（服务端）** | 解析 `attestationObject`（CBOR） | 注册校验失败 | #108 |

### 决定性的取证顺序

`.ai/conventions/8.5` 的「**先证伪『自己失败了』**」直接救场 —— 系统侧两句
`Final credential received from: …VaultixCredentialProviderService` /
`finishing session with propagateCancellation false` 证明**我方全对**，
于是嫌疑只能落在"交给对方的形态"，直接压到字段级，不必再猜密码学。

### 验收（同一判据、前后对比）

| 判据 | 修复前 `dev-4edf866` | 修复后 `dev-924dd85` |
|---|---|---|
| `MojoClassFromJSON … publicKeyAlgorithm` | **2 次** | **0 次** |
| `Failed to convert response from CredMan` | **2 次** | **0 次** |
| `Final credential received from …VaultixCredentialProviderService` | 在 | 仍在 |

用户确认（Edge + `console.cloud.tencent.com`）：**注册成功**。

### 修法要点

`WebAuthn.buildCreateResponseJson` 的 `response` 补齐四项（对齐 Bastion 的响应构造）：
`publicKeyAlgorithm`(int, ES256=-7) / `publicKey`(DER SPKI) / `authenticatorData` / `transports`。
★ **新增的三个入参刻意不给默认值** —— 少任何一个都在**调用方看不见的另一侧**失败，
让编译器强迫调用点显式提供，是防"静默不完整"的唯一可靠手段。

## 4. 当天新踩的环境坑

### adb（Windows + 无线调试）

- 设备 IP 由 `.114` 变到 **`.113`**；**端口每次无线调试重启都轮换**（当天见过 `46309 → 46191`）。
- ★ **daemon 在两次 Bash 调用之间会被回收** ⇒ 每条命令都要"重新发现 + connect"。
  自愈脚本：`C:/Users/chani/AppData/Local/Temp/adbready.sh`。
- 连上后 `adb devices` 常同时出现 `ip:port` 与 `mDNS 名`两个条目 ⇒ 一律带 `-s <serial>`。
- 装机核证用三重：`pm path` → `exec-out run-as … cat`（**不要用 `shell cat`**，会损坏二进制）
  → **比对字节数 + SHA-256**。

### 截图取证

- ⚠️ **`screencap` 是全分辨率**（本机 1256×2760 @560dpi），而用户粘贴的常是**缩略图**
  （如 422×905）—— 同一块状态栏像素高度差 3 倍。**采样前先读 PNG 头拿宽高**。
- 判断"前景是更白还是更黑"用 `ffmpeg … ,normalize=blackpt=black:whitept=white` 放大 4×，
  肉眼即可分辨极性（**只用来定极性，不要用它取绝对色值**）。

### 日志采集

- ★ **过滤不要用"保留所有 E/F 级"兜底**：这台 Honor 的 `afehal` / `WifiEnhanceServiceImpl` /
  `DeviceHalAidl` 会刷屏，40 秒灌 2000+ 行噪声把有用记录淹掉。改**纯关键字匹配**
  （Vaultix / Credential / passkey / WebAuthn / Autofill / CredMan / FIDO / KeyStore /
  Biometric / AndroidRuntime / FATAL / ActivityTaskManager）。
- 脚本：`C:/Users/chani/AppData/Local/Temp/logcap.py`（自愈重连 + 增量去重追加）。

### GitHub Actions 缓存

- 用量 **10.5 GB / 上限 10 GB**（93 条），已顶到上限 ⇒ 触发 LRU 淘汰、偶发冷启动变慢。
- 大头：`gradle-transforms-v2` **25 条 6.0 GiB**、`gradle-build-cache-v2` **27 条 2.1 GiB**（合计 82%）。
- 治本开关 **`gradle-home-cache-cleanup: true` 尚未开启**（保存缓存前剔除 Gradle Home 无用文件）。
