# AI 协作记忆

> 供 **AI 接力**使用。开工前必读，收工后必更新。

## 文件说明

| 文件 | 用途 |
|---|---|
| `MEMORY.md` | 项目长期约定：定位、架构、技术栈硬约束、代码来源与协议 |
| `ISSUES.md` | 踩过的坑（现象 → 根因 → 解法），**务必先读，避免重复踩** |
| `SESSION-YYYY-MM-DD.md` | 每次会话的工作日志 |

## 接力流程

1. 读 `MEMORY.md` —— 了解项目约定与硬约束
2. 读 `ISSUES.md` —— 避开已知坑（AGP 9 五连坑、Hilt 版本绑定必看）
3. 读 `Docs/progress/current-status.md` 与 `next-steps.md` —— 知道进度与下一步
4. 完成后**更新上述文件**；新坑写入 `ISSUES.md`

## 数据来源

本文件夹内容同步自 `.workbuddy/memory/`，两者保持一致。
